&#x20;Descrição



O ControleBiblioteca é um sistema desenvolvido para auxiliar no gerenciamento de uma biblioteca, permitindo organizar informações sobre livros e controlar funcionalidades relacionadas aos empréstimos.



&#x20;Objetivo



O objetivo do sistema é facilitar o cadastro e o gerenciamento dos livros, além de auxiliar no controle dos empréstimos realizados pela biblioteca.



&#x20;Público-alvo



O sistema é destinado a bibliotecas, bibliotecários e funcionários responsáveis pelo gerenciamento do acervo e dos empréstimos de livros.



&#x20;Principais funcionalidades



\* Cadastrar livros.

\* Consultar livros cadastrados.

\* Realizar empréstimos.

\* Renovar empréstimos.

\* Organizar e gerenciar as informações do acervo.
